This dataset contains information about students' performance in exams, including demographic details and test scores.

- Number of rows: 1000
- Number of columns: 8

Columns:
1- gender (object): Gender of the student (male/female)
2- race/ethnicity (object): Student group classification
3- parental level of education (object): Education level of parents
4- lunch (object): Type of lunch (standard or free/reduced)
5- test preparation course (object): Whether the student completed a preparation course
6- math score (int64): Score in mathematics (0–100)
7- reading score (int64): Score in reading (0–100)
8- writing score (int64): Score in writing (0–100)

The dataset contains no missing values and no duplicate records.

Source: Kaggle

This dataset is used for exploratory data analysis (EDA), including examining score distributions, comparing performance across different groups, and identifying relationships between variables such as gender, parental education, and test scores.
